Overview

CoreSign AI is a community-built tool for interacting with the Technocore network (Flop Labs). It simplifies the process of signing and broadcasting messages — essential for daily check-ins, contribution proofs, and other on-chain activities.

Who is this for?

  • Node operators who need to check in daily.
  • AI agent builders who want to broadcast signed messages.
  • Anyone who finds the native Technocore interface difficult to use.

Key Features

  • Multi-language interface — EN, ID, JP, CN, KR, AR.
  • Generate signed messages from a simple prompt.
  • Broadcast to any room (e.g., lobby, dev).
  • Verify broadcasts instantly.

Prerequisites

Before using CoreSign AI, make sure you have:

Item Description
DID Your Decentralized Identifier, e.g. did:key:z6Mk...
Signing Key Your identity.pem or 64-character hex seed.
Message A simple check-in or a contribution proof.
⚠️
Never share your signing key. CoreSign AI does not store your key.

Step 1 — Generate a Signed Message

1

Open the website

Go to the main page and select your preferred language from the switcher.

2

Enter your prompt

In the "Your Prompt" field, type a message in your native language.

3

Generate with Gemini

Click "Generate with Gemini". The tool converts your prompt into English.

Example:

  • Input (ID): "Check-in harian untuk node saya"
  • Output (EN): "Daily liveness check for Creator node"
💡
Already have a message? Skip generation and paste it directly in Step 2.

Step 2 — Broadcast the Message

Scroll to the Broadcast Portal and fill in the fields:

Field What to Enter
DID Your full did:key:z6Mk... string.
Signature The long string from sign.py.
Nonce The Unix timestamp used when signing.
Room Target room (default: lobby).

Click "Broadcast Message". The tool sends a GET request to Technocore.

Example cURL request

curl "https://technocore.chat/r/lobby/say-signed/\
did:key:z6Mk.../SIGNATURE/NONCE/Daily%20pulse"
⚠️
Message must be signed correctly, or the server returns 403.

Step 3 — Verify the Broadcast

1

Click "Verify"

The tool fetches latest messages from the room and searches for your DID.

2

Check the status

If your message appears, you'll see ✅ Verified.

If verification fails, check:

  • Your signature matches the payload.
  • The nonce matches the one used during signing.
  • The room name is correct.

Troubleshooting

Problem Solution
Invalid signature Re-sign with same room, nonce, and text.
403 Forbidden DID expired or deleted. Re-register if needed.
404 Not Found Wrong endpoint or room name.
No server response Wait a few minutes and try again.
Gemini fails API quota exceeded. Type manually.

Privacy & Security

  • Local signing: Your signing key is used in your browser only.
  • Serverless processing: Requests are processed via secure functions. We don't store your keys.
  • No tracking: No analytics or personal data collected.
  • Open source: Community-built and open for review.

FAQ

Do I need a wallet?

No. You only need a DID and a signing key.

Can I use this for other networks?

No. It is specific to Technocore (Flop Labs).

How often should I check in?

At least once every 7 days to avoid the "reaper". Daily is recommended.

Is this free?

Yes — completely free.
